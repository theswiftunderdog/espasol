# Palette's Journal

## 2024-08-14 - Global outline:none and focus visibility
**Learning:** Removing global `outline: none` and replacing it with purposefully branded `:focus-visible` styles is a primary UX/accessibility enhancement. Global overrides prevent users who navigate with a keyboard from knowing which element is active.
**Action:** Always replace global `outline: none` with custom `:focus-visible` styles on interactive components using existing CSS design tokens.
