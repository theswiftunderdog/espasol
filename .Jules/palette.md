## 2026-08-07 - Focus Visible Restored and Form Accessibility Enhanced
**Learning:** Legacy global `outline: none` rules completely break keyboard-only navigation by hiding focus rings. Removing global `outline: none` and implementing branded `:focus-visible` styles with a 2px offset ensures high-contrast focus rings align beautifully with standard design tokens while preserving full visual focus tracking. Additionally, forms using inputs without `<label>` tags are inaccessible to screen readers, so we must pair them with visually hidden `.sr-only` labels.
**Action:** Always audit stylesheets for global `outline: none` and replace with high-contrast `:focus-visible` focus outlines. Ensure form fields always have associated visually hidden labels if placeholder-only designs are required.
