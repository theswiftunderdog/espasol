## 2024-05-26 - [Form Accessibility with sr-only Labels and Focus States]
**Learning:** In minimal UI designs that rely on placeholders for input identification, accessibility is often compromised for screen reader users and keyboard navigators. Using a `.sr-only` class allows for semantic `<label>` elements that are invisible to sighted users but essential for assistive technology. Furthermore, the common practice of `outline: none` destroys focus indicators; replacing it with `:focus-visible` and theme-aware outlines restores accessibility without impacting the hover-state aesthetics for mouse users.
**Action:** Always implement a `.sr-only` utility and apply it to form labels when visible labels are not part of the design. Explicitly define `:focus-visible` styles using theme variables to ensure high contrast and clear navigation paths.
